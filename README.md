# Imóveis Recife

Plataforma de imóveis de alto padrão em Recife e região metropolitana de Pernambuco.

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (PostgreSQL, Auth, Storage, Edge Functions)
- Framer Motion

## Desenvolvimento local

Pré-requisitos: Node.js 18+ e npm.

```sh
npm install
npm run dev
```

## Deploy

Para promover alterações para a versão pública, use o botão **Publish > Update**.

## Domínio personalizado

Para conectar um domínio próprio, acesse **Project > Settings > Domains** e clique em **Connect Domain**.
